# News Website Project

## Project Overview
Create a news website for a fictitious news organization. The site will feature credible or fake news on a chosen subject (general news, sport, technology, satire, etc.).

## Team Roles
- Language Editor
- Content Editor
- Web Design
- Fact Checker
- Video Editor

## Content Requirements
1.  **Hard News Article**: 200-word news article (Class 6 assignment).
2.  **Editorial**: 150-word opinion piece (Class 8 assignment).
3.  **News Video**: ~2 minutes long (interview, report, debate, etc.).
4.  **Pitch**: Presentation for investors (Last class).

## Key Sections
- **Home**: Overview of news.
- **News**: Hard news articles.
- **Opinion**: Editorials.
- **Video**: News video content.
- **About/Pitch**: Information about the organization and the team.

## Grading
- Hard News Article: 20%
- Editorial: 20%
- News Website: 35%
- In Class Participation: 25%
